# Monitor de Red

Aplicación web inicial para monitorear equipos de planta.

## Grupos actuales

- APS
- SW
- CAM
- RFID
- LEXMARK
- MPC (pendiente)
- SATO (pendiente)

La interfaz está diseñada para 1024x720 y preparada para agregar comprobación real de estado desde Windows.

## Importante

La versión actual es la interfaz y catálogo de IPs. El navegador por sí solo no puede hacer ping a IPs arbitrarias de la red local. El siguiente paso será agregar un pequeño servicio local para que la aplicación pueda comprobar las IPs realmente y mostrar ONLINE/OFFLINE.
